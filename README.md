# Desk

给工作时复习考研英语用的小窗口。没有提示音，窗口没有系统标题栏。

## 打开

双击本文件夹里的 `start.bat`。

或在本文件夹打开终端后执行：

```
npm start
```

Electron 已经装在本文件夹的 `node_modules` 里。不要删这个目录，也不要全局安装。若以后要重装，`start.bat` 会从这个文件夹安装，并改用镜像下载 Electron。

改完词表或进度后，要从托盘图标右键选「退出」，再重新打开。直接关窗口只是收到托盘，程序还在。

## 怎么用

窗口顶部可以拖动。右上角：

- 「置顶」：学习窗口留在最前面。桌宠模式下本来就浮在上面，这个开关管的是展开后的学习窗口。
- 「桌宠」：窗口收成一株可以拖动的小植物，停在桌面上，不进任务栏。植物下面是当前要背的词。点「展开」回到学习窗口。
- 「加词」：写一个新词，可以有多条词性加中文释义。
- 「×」：收到系统托盘，不退出。

当前这个词下面有「更改」和「删除」。

- 「更改」用来改英文写法、音标，或补一条你后来发现的释义。复习记录还留在原来的词上。内置词的改动写进 `data\progress.json`，不会改 `vocab-a.txt` 这类词表。
- 「删除」再点一次「确认删除」才生效。自加词会连同复习记录一起去掉。内置词只是不再出现，词表文件还在。

先看词，回忆义项，再显示释义，然后打分。窗口在前台、而且不是桌宠时：

- 空格或回车：显示释义
- 1 忘了，2 模糊，3 记得，4 轻松

这些键只在 Desk 处于前台时有效。在别的软件里打字不会翻开释义，也不会打分。默认没有全局热键，也没有声音。

托盘图标：

- 左键：打开学习窗口。如果当时是桌宠，会先展开。
- 右键：「打开学习窗口」「变成桌宠」「隐藏」「置顶」「退出」。

「隐藏」才是把窗口完全收起来。左下角的小植物会一直轻轻动。

底部「每日新词」可在 10、20、30、50 之间切换。到期的旧词不受这个上限限制。这一批背完后，如果还有没学过的词，可以「再看 10 个」。

## 换一套词库

词库由 `data\decks.txt` 决定。一行一个词表文件名，文件要和 `decks.txt` 放在同一个 `data` 文件夹里。以 `#` 开头的行是说明，会被忽略。

现在的内容是：

```
vocab-a.txt
vocab-b.txt
```

想换成自己的词库时，把新的 txt 放进 `data`，再把 `decks.txt` 改成只写那个文件名，例如：

```
# 只用我自己的词表
my-words.txt
```

也可以同时写多份，程序会按顺序合成一份。两个文件里不能有同一个英文词（大小写不算区别）。

词表每一行的格式是：

```
英文|音标|词性:中文|词性:中文
```

例如：

```
approach|/əˈprəʊtʃ/|v.:靠近，接近|v.:着手处理|n.:方法，途径
```

规则：

- 至少两个义项。词性只能是 `n.` `v.` `adj.` `adv.` `prep.` `conj.` `pron.` `art.` `num.` `aux.` `phrase`。
- 用英文竖线 `|` 分开各段，用英文冒号 `:` 分开词性和释义。音标里如果有两个读音，用中文分号 `；`，不要用 `|`。
- 文件名只能是字母、数字、下划线、点、连字符，并且以 `.txt` 结尾。不要把 `decks.txt` 自己写进去，也不要写文件夹路径。
- 空行和 `#` 开头的行会被跳过。
- 改完后从托盘退出再打开。如果某一行格式不对，窗口会起不来，终端里能看到是哪一行。

在学习窗口里改过的词，按原来的英文（小写）记在进度里。新词库里如果还有同一个拼写，那些改动还会套上去。删掉的内置词也按这个拼写记住，换词库后同一个拼写仍然不会出现。

## 打包成软件

在本文件夹执行：

```
npm install --save-dev electron-builder
npm run pack
```

完成后，软件在 `release\win-unpacked\Desk.exe`。把整个 `win-unpacked` 文件夹拷走即可，不要只拷那一个 exe。

第一次打开打包后的程序时，它会在 `Desk.exe` 旁边生成 `data` 文件夹，并把自带的 `vocab-a.txt`、`vocab-b.txt`、`decks.txt` 复制过去。之后换词库，改的是 exe 旁边的 `data`，不是安装包里面的文件。进度也写在 exe 旁边的 `data\progress.json`，不会打进安装包。

这里用的是文件夹形式，不是单个便携 exe。单个 exe 每次都会解压到临时目录，你改过的词库和进度会丢。

打包不签名。若杀毒软件拦截，把 `release\win-unpacked` 加为例外，或继续用 `start.bat`。

## 进度存在哪

开发时：

`D:\Data\Work\gameforEng\data\progress.json`

里面有复习记录、自己加的词、对内置词的修改、已删除的内置词、每日新词数量、窗口位置，以及桌宠的位置。

## 限度

- 内置词表有 1343 个高频词，每个至少两个义项。不是完整的约 5500 考研大纲。
- 每天默认引入 20 个新词。到期的旧词不受这个上限限制。
- 「忘了」会在后面几个词之后再出现；如果它是这一批的最后一个，大约 10 分钟后再出现。
- 没有声音，没有账号，也不会把进度传到网上。
- 音标是学习用注音。名词和动词重音不同时，音标里会并列两个读音。
