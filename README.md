# Desk

给工作时复习考研英语用的小窗口。没有提示音，窗口没有系统标题栏。

## 打开

双击本文件夹里的 `start.bat`。

或在本文件夹打开终端后执行：

```
npm start
```

Electron 已经装在本文件夹的 `node_modules` 里。不要删这个目录，也不要全局安装。若以后要重装，`start.bat` 会从这个文件夹安装，并改用镜像下载 Electron。

改完词表或进度后，要从托盘图标右键选「退出」，再重新打开。直接关窗口只是收到托盘，程序还在。

## 怎么用

窗口顶部可以拖动。窗口最下面一行会写出当前画面能用的键。这些键只在 Desk 处于前台、而且光标不在输入框里时有效。默写或检索时，字母仍是在打字。在别的软件里打字不会翻开释义，也不会打分。默认没有全局热键，也没有声音。上班时可以把窗口置顶，留在桌面角落。

右上角：

- 「置顶 P」：学习窗口留在最前面。桌宠模式下本来就浮在上面，这个开关管的是展开后的学习窗口。
- 「桌宠 M」：窗口收成 `pet.png` 里的图片，可以拖动，停在桌面上，不进任务栏。图片下面是当前要背的词。按 M，或点「展开 M」，回到学习窗口。学习窗口里再按 M 又收成桌宠。默写框里打字时 M 仍是字母。
- 「词表 B」：翻看当前词表，不改复习进度。再按 B，或点「回到背词」，回到刚才那个词。
- 「加词 A」：写一个新词。自己加的词至少一条中文释义，可以有多条词性，每条词义可以加例句。「保存并继续」接着写下一条，「完成」才关掉。写到一半点「完成」会先把这一条存上。
- 「×」：收到系统托盘，不退出。

当前这个词下面有「更改 E」和「删除 D」。

- 「更改 E」用来改英文写法、音标，或补一条你后来发现的释义。复习记录还留在原来的词上。内置词的改动写进 `data\progress.json`，不会改 `vocab-a.txt` 这类词表。
- 「删除 D」再点一次「确认删除 D」才生效。自加词会连同复习记录一起去掉。内置词只是不再出现，词表文件还在。

先看词，回忆中文，再显示释义，然后打分。窗口在前台、而且不是桌宠时：

- 空格或回车：显示释义
- 1 忘了，2 模糊：过几个词再出现。这一轮里还没看过的词会排在前面，不会被卡在前几个
- 3 记得，4 轻松，0 已会：先背后面几个词，再凭中文把英文写出来。写对才按这个档安排下次
- 默写写错先再写一次，不会马上记成「忘了」。还错就这一轮后面再默写，英文不会提前露出来。写对才按原来那个档安排下次。Esc 回到刚才那个词
- 打开后，这一轮会带上当前词表里所有到期的词，以及还没学过的词。已经记下、还没到复习时间的词不会被提前拉回来
- 这一批背完后，如果还有没排进来的新词，回车或「加上剩下的新词」会把剩下的都加进来

### 词表

按 B 或点「词表 B」进入。只是查看，复习进度不变，回到背词时还是原来那一张。每个词会自动记下加入的日期，列表、逐词和句子里都能看到「添加于几月几日」。不用自己填。新加的词记当天。自己加过、却还没有日期的词，下次打开时补成当天。词表文件里原来就有、还没背过的词，不拿今天去充数。

- F：检索框。英文、中文释义、例句都能对上。Esc 离开检索框，检索词还留着
- L 列表：一屏很多词。↑ ↓ 移动，点一行就进入这个词的逐词页
- C 逐词：一次一个词。← → 或 ↑ ↓ 翻
- S 句子：每条词义只带着自己的例句。某一条没有例句，句子页里就不出现它。一个词都没有例句时，页面会说明怎么加
- V：在词表原来的顺序和 A–Z 之间切换

先看，再改。按 E 才进入「编辑模式」，这时才会出现「更改 G」。例句写在对应的那一条词义下面，不单独堆在整个词的底下。加词时也可以直接写。一条词义最多四句，英文要写，中文可以空着。释义和例句太长时会折行，开头仍看得到。再按 E 变成「完成编辑」，或按 Esc，就退出编辑模式，之后不能改。编辑模式下按 Esc 只退出编辑，再按一次才回到背词。

托盘图标：

- 左键：打开学习窗口。如果当时是桌宠，会先展开。
- 右键：「打开学习窗口」「变成桌宠」「隐藏」「置顶」「退出」。

「隐藏」才是把窗口完全收起来。左下角的图片会一直轻轻动。进度写在 `data\progress.json` 里。

## 换一套词库

词库由 `data\decks.txt` 决定。一行一个词表文件名，文件要和 `decks.txt` 放在同一个 `data` 文件夹里。以 `#` 开头的行是说明，会被忽略。

现在的内容是：

```
#vocab-a.txt
#vocab-b.txt
vocab-KY.txt
```

`#` 开头的两行不起作用，所以当前只用 `vocab-KY.txt`。想改回原来的两份高频词，去掉那两行开头的 `#`，并把 `vocab-KY.txt` 那一行注释掉或删掉。

想换成自己的词库时，把新的 txt 放进 `data`，再把 `decks.txt` 改成只写那个文件名，例如：

```
# 只用我自己的词表
my-words.txt
```

也可以同时写多份，程序会按顺序合成一份。两个文件里不能有同一个英文词（大小写不算区别）。

词表每一行的格式是：

```
英文|音标|词性:中文|词性:中文
```

例如：

```
approach|/əˈprəʊtʃ/|v.:靠近，接近|v.:着手处理|n.:方法，途径
```

规则：

- 至少两个义项。词性只能是 `n.` 名词、`v.` 动词、`vi.` 不及物动词、`vt.` 及物动词、`adj.` 形容词、`adv.` 副词、`prep.` 介词、`conj.` 连词、`pron.` 代词、`art.` 冠词、`num.` 数词、`aux.` 助动词、`phrase` 短语。加词时下拉里能看到这些中文。
- 用英文竖线 `|` 分开各段，用英文冒号 `:` 分开词性和释义。音标里如果有两个读音，用中文分号 `；`，不要用 `|`。
- 文件名只能是字母、数字、下划线、点、连字符，并且以 `.txt` 结尾。不要把 `decks.txt` 自己写进去，也不要写文件夹路径。
- 空行和 `#` 开头的行会被跳过。
- 改完后从托盘退出再打开。如果某一行格式不对，窗口会起不来，终端里能看到是哪一行。

在学习窗口里改过的词，按原来的英文（小写）记在进度里。新词库里如果还有同一个拼写，那些改动还会套上去。删掉的内置词也按这个拼写记住，换词库后同一个拼写仍然不会出现。

## 打包成软件

在本文件夹执行：

```
npm install --save-dev electron-builder
npm run pack
```

完成后，软件在 `release\win-unpacked\Desk.exe`。把整个 `win-unpacked` 文件夹拷走即可，不要只拷那一个 exe。

第一次打开打包后的程序时，它会在 `Desk.exe` 旁边生成 `data` 文件夹，并把自带的 `vocab-a.txt`、`vocab-b.txt`、`decks.txt` 复制过去。之后换词库，改的是 exe 旁边的 `data`，不是安装包里面的文件。进度也写在 exe 旁边的 `data\progress.json`，不会打进安装包。

这里用的是文件夹形式，不是单个便携 exe。单个 exe 每次都会解压到临时目录，你改过的词库和进度会丢。

打包不签名。若杀毒软件拦截，把 `release\win-unpacked` 加为例外，或继续用 `start.bat`。

## 进度存在哪

开发时：

`D:\Data\Work\gameforEng\data\progress.json`

里面有复习记录、自己加的词、对内置词的修改和例句、已删除的内置词、窗口位置，以及桌宠的位置。

## 限度

- `vocab-a.txt` 和 `vocab-b.txt` 里一共有 1343 个高频词，每个至少两个义项。不是完整的约 5500 考研大纲。当前 `decks.txt` 没有启用它们。
- 一轮学习包含当前词表里所有到期的词，以及还没学过的词。还没到复习时间的词留在原来的日子。
- 一条词义最多四句例句，跟在那一条释义后面。
- 「忘了」和「模糊」会在后面几个词之后再出现；如果它是这一批的最后一个，大约 10 分钟后再出现。
- 「已会」写对以后，新词大约 21 天后再见。已经隔得更久的词会隔得更开。
- 默写不区分大小写，多余空格不算错。
- 没有声音，没有账号，也不会把进度传到网上。
- 音标是学习用注音。名词和动词重音不同时，音标里会并列两个读音。
